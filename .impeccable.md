# learn_wiki

A personal knowledge-graph wiki. It ingests sources (web pages, videos), extracts a typed entity graph with Claude, and presents it as an explorable 3D graph and a browsable wiki, with the eventual goal of surfacing patterns for engineering AI products.

## Design Context

### Users
A single power user (the creator) using this as a serious personal research tool. Context of use: curating sources, exploring the resulting knowledge graph, browsing entity pages, and hunting for cross-source patterns. Not a mass-market or multi-user product - depth and signal matter more than onboarding or hand-holding.

### Brand Personality
Three words: precise, luminous, intentional. The voice is quiet and confident, not chatty or salesy. The interface should feel like a well-made instrument - a "mission control for ideas" - that rewards attention. Emotional goal: premium and impressive; the user should feel this is a real product, not a script, and feel focused and in command when using it.

### Aesthetic Direction
Refined dark observatory. Dark theme only.

- A tuned, layered near-black palette with a subtle cool hue tint (never flat, never pure `#000`). Surfaces differ by luminance to convey depth.
- The data is the light: the 3D graph, entity names, and relationships glow against restrained, low-key chrome. Color is reserved to carry meaning (entity-type coding), not decoration.
- Precise, characterful typography with clear hierarchy: a distinctive display face for headings/brand and a clean, refined humanist sans for body/UI. No `system-ui` default stack, no monospace used as lazy "technical" shorthand (a mono face may appear only for genuine data/labels, sparingly).
- Restrained accents. One calm signal color for interaction plus the meaningful type palette; no neon-on-black, no purple-to-blue gradients, no gradient text.
- Confident, high-craft moments (a composed page-load reveal, the graph as centerpiece) rather than scattered micro-interactions.

Anti-references: generic dark-dashboard "AI slop"; flat undifferentiated dark backgrounds; glassmorphism and glow borders used decoratively; cards-inside-cards; identical icon+heading+text card grids; cyan/neon accents; bouncy/elastic motion.

### Design Principles
1. Depth through tuned darkness - layered near-blacks with a subtle hue tint, so surfaces read as space, not a void.
2. Data is the light - content and the graph carry luminance and color; chrome stays quiet. Color always means something (entity type, state), never mere decoration.
3. Typographic precision - a real type system with a distinctive display face and a refined body sans, strong hierarchy, generous and rhythmic spacing. No default or mono-as-decoration.
4. Quiet chrome, confident moments - restrained surfaces with one or two orchestrated, high-craft moments; smooth ease-out motion only, purposeful, honoring reduced-motion.
5. Everything intentional - no filler containers, no glassmorphism for its own sake, nothing that would make someone say "an AI made this."

### Constraints
- Stack: FastAPI serving static pages; vanilla JS with no build step; `3d-force-graph` (Three.js) for the graph. Keep it lean - no frontend framework.
- Fonts must be vendored or loaded without a build step and work offline where practical.
- Respect `prefers-reduced-motion`.
